核心概念速览

三个问题理解大模型训练

01

模型在学什么？

本质只有一件事：根据前文预测下一个 token。一句话里每个词都是一个训练信号，所以海量文本 = 海量练习题。

P(x) = ∏ P(xₜ | x<t)
02

微调在改什么？

全量微调改所有权重；LoRA 只学一个低秩增量 ΔW=BA，训练完还能合并回去，推理零开销。

W′ = W₀ + (α/r)·BA
03

多模态多了什么？

给 LLM 加一只"眼睛"：ViT 把图像切成 patch token，投影层把它们对齐到词的语义空间，再和文本一起送进 LLM。

图像 → ViT → MLP → LLM

LoRA 手写实现 · 逐行中文注释
# ① 冻结原权重：优化器不会碰它
for p in base.parameters(): p.requires_grad = False

d, k = base.weight.shape          # 输出维度 / 输入维度
self.scaling = alpha / r          # ② 真正生效的缩放是 α/r

# ③ A 随机初始化；B 全 0 → 训练开始时增量 ΔW=0，不破坏原模型
self.A = nn.Parameter(torch.empty(r, k));  kaiming_(self.A)
self.B = nn.Parameter(torch.zeros(d, r))

def forward(self, x):
    return base(x) + (x @ self.A.T @ self.B.T) * self.scaling
    #       W₀x    +        ΔW x       → 叠加低秩增量

def merge(self):
    base.weight.data += self.scaling * (self.B @ self.A)
    # 训练后合并回原权重 → 推理零额外延迟（LoRA 的决定性优势）

视觉-语言模型架构（3D）

拖拽旋转 · 观察图像 token 的流向
①
ViT 视觉编码器

图像切 P×P patch，线性投影成视觉 token：N = HW/P²

②
MLP 投影层（对齐桥梁）

H_v = MLP(V) ∈ ℝ^(N×d_l)，把视觉特征映射到 LLM 词嵌入空间

③
拼接 + LLM 自回归生成

图像 token 与文本 token 拼接，只对回答部分计算 loss

L = −Σt∈回答位置 log P(yₜ | y<t, H_v, x)
